- **CFDI 4.0**: Specific field extraction for tax compliance
- **Flexible LLM**: Support for Gemini, OpenAI, Ollama

#### **Hybrid OCR Service:**
- **File**: `backend/src/services/hybrid_ocr_service.py`
- **Combines**: Azure Document Intelligence + LangExtract
- **Intelligent Fallback**: Mechanisms for optimal processing
- **Cost Optimization**: Strategies for efficient processing
- **Service Detection**: Availability detection for different services

#### **API Integration:**
- **Endpoints**: 
  - `POST /api/v1/ocr/langextract` - LangExtract-only processing
  - `POST /api/v1/ocr/hybrid` - Hybrid processing
  - `GET /api/v1/ocr/status` - Service status check
  - `POST /api/v1/ocr/visualize` - Create visualizations

#### **Testing Results:**

- **Costco Receipts**: RFC, fiscal regime, membership, cashier details
- **HEB Receipts**: Complete CFDI compliance fields

### August 14, 2025 - Initial Setup
