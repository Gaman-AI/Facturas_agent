### 2025-08-05 21:25 - Python Dependencies Fix (psutil Module)

**Issue**: Backend was throwing `ModuleNotFoundError: No module named 'psutil'` when executing browser-use agent tasks.

**Root Cause**: The browser-use Python package requires `psutil>=7.0.0` as a dependency, but the Python environment where the agent was running didn't have the required dependencies installed.

**Fix Applied**:
- Created a Python virtual environment in `backend/browser-use/.venv` using `uv` package manager
- Set Python version to 3.11.7 (where `uv` is available) instead of 3.12
- Installed all dependencies from `pyproject.toml` using `uv sync`
- Updated `backend/src/services/pythonBridge.js` to use the virtual environment's Python executable
- Modified the Python process spawn configuration to include virtual environment paths

**Files Modified**:
- `backend/src/services/pythonBridge.js` - Updated to use virtual environment Python executable
- `backend/browser-use/.venv/` - Created virtual environment with all dependencies

**Commands Executed**:


### 2025-08-05 21:20 - Complete Backend Process Import Fix

**Issue**: Backend was throwing `ReferenceError: Cannot access 'process' before initialization` when clicking "Start Task" button.

**Root Cause**: Multiple files were using `process.env` and `process.cwd()` without importing the `process` module in ES modules.

**Fix Applied**:
- Added `import process from 'process'` to all files using process variables:
  - `backend/src/services/pythonBridge.js` - Fixed variable naming conflict and added process import
  - `backend/src/services/browserService.js` - Added process import
  - `backend/src/index.js` - Added process import
- Renamed local `process` variable to `pythonProcess` in pythonBridge.js to avoid shadowing

**Files Modified**:
- `backend/src/services/pythonBridge.js` - Fixed variable naming conflict and added process import
- `backend/src/services/browserService.js` - Added process import  
- `backend/src/index.js` - Added process import

**Testing**: Backend should now properly execute Python tasks without the process initialization error.
